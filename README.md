# GitSense

AI-powered repository intelligence platform for Gitlawb.

GitSense helps developers instantly analyze repositories using AI.

---

## Features

- AI repository analysis
- Dependency mapping
- Security intelligence
- Contributor insights
- Repo health scoring
- Ecosystem monitoring

---

## Stack

- Next.js
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Vercel

---

## Getting Started

```bash
npm install
npm run dev
```

GitSense transforms repositories into intelligent systems powered by AI.
